# 合并转发阅读

QQ 的合并转发消息在 AstrBot 里只有一个 `Forward(id)` 占位符，模型看不到里面的内容。本插件在消息进入合流/LLM 之前调用 OneBot `get_forward_msg`，把节点展开成：

```
昵称：内容
昵称：[图片]
昵称：内容
```

支持多层嵌套（默认最多 3 层），每层最多 60 条、总字数 6000，防止超长转发撑爆上下文。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| enabled | true | 总开关 |
| max_depth | 3 | 最多展开几层嵌套；0 = 只看最外层 |
| max_nodes | 60 | 每层最多读多少条 |
| max_chars | 6000 | 展开后的最大字数 |

## 说明

- 只展开、不发送；不会替她转发或评论
- 图片/视频在文本里只保留 `[图片]`/`[视频]` 占位，不会额外下载（要看图仍走正常图片理解）
- 读取失败（消息过期、协议端不支持）会静默跳过，不影响正常回复
