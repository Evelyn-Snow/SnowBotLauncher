# Bot 真实经历

让机器人拥有**真实发生过**的经历：她会自主下载公版书来读、检索资料、翻阅论文（每周限次），把收获写成第一人称笔记；这些经历会注入后续聊天（能自然聊起"昨天读的那本书"），并被自动日记引用。

> 需要配合「虚拟人生」插件（astrbot_plugin_virtual_life）：虚拟日程提供生活框架，本插件往里面填入真实事件。检测不到虚拟人生时本插件完全静默。

## 三类事件（每周限次，ISO 周重置）

| 事件 | 内容 | 默认配额 |
|---|---|---|
| 读书 | 优先读电子书库里没读完的书（续读到上次位置）；书库空了才从古腾堡公版书自动下载（**仅限 txt 格式**、中文优先、≤8MB，失败不耗次数） | 2 次/周 |
| 查资料 | 按兴趣关键词池用 DeepSeek 搜索并整理成笔记 | 3 次/周 |
| 读论文 | arXiv 按关键词检索，下载 **PDF 正文**阅读（失败退回摘要）后写中文笔记，PDF 存进 `papers_dir` | 1 次/周 |
| 写作 | 按兴趣话题真的写一篇 900-1200 字课程小论文，存成 Markdown（`writing_dir`），之后可以通过发文件功能发给你 | 2 次/周 |
| 刷手机 | 刷 B站热门和小黑盒信息流，按兴趣词筛选后挑 1-2 条写第一人称记录，存进 `browsing_dir` 并注入聊天 | 3 次/周 |

## 事件连续性

同一类事件会承接上一次，而不是每次从头随机：

- **读书**：在「最近在读」和「没读过」里各取前几本加权抽，未读完权重默认是未读的 2 倍；选中后从该书的 offset 继续读，所以会并行开几本、又略微偏向续读
- **查资料**：读取最近几条查资料记录，让模型顺着上次的线索生成一个更具体的新查询；没有历史才退回兴趣词池
- **读论文**：优先沿着最近查资料/读论文的方向生成英文 arXiv 检索词，失败再退回内置话题映射
- **写作**：优先沿用最近一次查资料或读书的话题
- **刷手机**：优先用本地 bge-m3（`snowbot-memory`）把兴趣词和条目做语义相似度排序；向量不可用时退回关键词打分。再按去重和视频/平台偏好收尾，不产生 API 费用

## 支持阅读的文件

书库（`books_dir`）里放以下格式，她会按「没读过 → 读到一半」的顺序自动读。**支持子文件夹**：可以按系列分文件夹放（如 `【轻小说】狼与香辛料/狼与辛香料 Ⅰ.epub`），扫描是递归的，同系列的书会排在一起依次读：

| 格式 | 说明 |
|---|---|
| `.txt` / `.md` | 直接读 |
| `.epub` | zipfile 抽 XHTML 正文 |
| `.pdf` | 用 `pypdf` 抽文字层；扫描件/加密 PDF 读不出文字 |
| `.docx` | 用 `python-docx` 读段落和表格；没装时用 zipfile 兜底读段落 |
| `.html` / `.htm` | 去标签后读 |

**知网格式**：`.caj` / `.kdh` / `.nh` 是知网的私有容器格式，不内置解析。知网大多数文献也能下 PDF，优先下 PDF；只有 CAJ 时，用 CAJViewer 打开后「另存为 PDF」放进书库即可。老式 `.doc` 也建议先另存为 `.docx` 或 PDF。

- **`.mobi` / `.azw3` 不支持**，请先用 Calibre 等工具转成 `.epub` 再放进书库
- 解压开的 epub 目录（根部有 `mimetype` 文件）会被整体跳过，里面的章节碎片不算书；请放回打包好的 `.epub` 文件
- 超长书的正文提取上限约 400 万字，超出部分读不到（绝大多数单本小说不会触顶）

- 每天最多 1 个事件，触发时刻按日期种子固定在 `event_window` 时段内（重启不重排）
- 触发时虚拟人设若在睡觉，事件推迟（不在梦里查论文）
- 执行失败（下载超时/搜索无结果/模型失败）不消耗配额，下个 tick 重试
- 事件记录按月归档：同类型每月一个文件（如 `2026-11-book.md`、`2026-11-research.md`），每个事件一个 `##` 小节

## 联动

- **聊天注入**：最近 2 条经历 + 真实「在读」状态（书名和进度百分比）注入 system_prompt，并带防幻觉守卫——没提到的书不说读过、没写到的情节不编、没读到就说没读到；日程里的「睡前看书」如果背后没有真实阅读记录，也只会说在看而不会编情节
- **自动日记**：obsidian_notes 插件（v0.3.2+）写日记时会带上今天的虚拟日程和最近真实经历
- **兴趣来源**：`topics` 配置（逗号分隔）决定选书/查资料/论文的方向；留空用内置通用池

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| enabled | true | 总开关 |
| books_dir | 空 | 电子书库目录；留空用插件数据目录 books/，可手动放 txt/md/epub/pdf/docx |
| papers_dir | 空 | 她下载的论文 PDF 存放目录；留空用插件数据目录 papers/ |
| topics | 空 | 兴趣关键词池（逗号分隔） |
| event_window | 10:00-21:00 | 事件触发时段 |
| event_chance | 0.7 | 每天触发概率 |
| weekly_book / weekly_research / weekly_paper / weekly_writing | 2 / 3 / 1 / 2 | 每周各类型上限 |
| reading_parallel / reading_partial_bias | 3 / 2.0 | 同时读几本、续读相对未读的权重 |
| share_events_to_qzone | true | 刷手机/写作完成后按概率发一条说说（需安装 qzone 插件） |
| qzone_share_chance / qzone_share_daily_limit / qzone_share_types | 0.5 / 1 / browsing,writing | 发说说概率、每天上限、允许分享的事件 |
| writing_dir | 空 | 写作事件保存目录；留空 = 插件数据目录 writings/ |
| browsing_dir | 空 | 刷手机记录目录；留空 = 插件数据目录 browsing/ |
| weekly_browsing / browsing_items / browsing_minutes | 3 / 2 / 15 | 每周次数、每条数、每次时长 |
| inject_limit_chars | 380 | 聊天注入经历的最大字数 |

## 依赖

- **pypdf**（必装，读 PDF 正文）；**python-docx**（可选，读 docx 表格更完整，没装时用标准库兜底读段落）。
- AstrBot 会按 `requirements.txt` 自动安装；也可以手动 `pip install pypdf python-docx`。
- 需要已配置 DeepSeek 搜索（查资料事件用，与 AstrBot 内置 web_search 同一份 Key）。
- arXiv XML 用标准库解析，epub/html 用标准库，不依赖第三方。
