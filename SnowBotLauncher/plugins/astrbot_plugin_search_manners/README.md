# 搜索礼仪

联网搜索工具由 AstrBot 内置（`provider_settings.web_search` + 搜索源 Key）；
本插件控制它的行为：

- **明确要求必搜**：用户说“搜索一下”“查一下”“百度一下”等，模型必定调用搜索工具并附来源
- **平时低频**：自发搜索两次至少间隔 `min_interval_minutes` 分钟、每天最多 `max_per_day` 次
- **表述规范**：自发搜索时先表明“这个我不太清楚”，再说明在网上看到的内容和来源
- 被频率挡掉时，模型会直接基于已有知识回答并坦率说不确定

显式关键词固定为：搜索 / 搜一下 / 查一下 / 百度一下 / 上网查 / 联网查 / search 等。

状态文件：插件数据目录 `search_state.json`，重启后有效。
