# Bot 印象笔记

为每个聊天对象维护一份**持续更新的印象笔记**：以 QQ 号为唯一索引（昵称随时会变，只作展示并记录改名史），每人一个 `<QQ号>.md`，聊天时自动把这份印象注入上下文，让机器人越聊越懂对方。

**笔记用她自己的性格、第一人称写**——是「我眼里的TA」，不是客观档案：可以带情绪、有亲近或疏远的判断，提到对方用昵称或「他/她」，提到自己用「我」。旧版本写成的第三人称档案，会在下一次更新时一并改写成第一人称。

## 行为

- **采集**：每次「TA 说 / 我答」的交流按用户归档（含群成员，可配置），默认网页测试台不计入
- **更新**：同一用户攒够新素材（默认 6 条）且过了门槛（间隔默认 3 小时、每天最多 4 次、凌晨静默）才调用一次模型重写笔记正文；frontmatter（昵称、曾用名、互动次数、更新时间）由插件管理，不消耗模型
- **注入**：对方来消息时，把笔记精简版（默认 ≤400 字，标记为「我记下的TA」）注入本轮上下文，模型可自然参考但不会复述
- 笔记章节：我眼里的TA / TA说话的样子 / 我们常聊什么 / 跟TA相处要注意什么 / 最近的事；只写对话中有依据的内容，不编造

## 文件

默认存放在插件数据目录 `profiles/`；可在配置里填任意绝对路径（例如 Obsidian 仓库下的「画像」文件夹），方便直接翻看编辑。文件以 QQ 号命名，手改后下次更新会以你的版本为基础继续合并。

## 出站隐私（v0.6.1）

- **发给模型前**会清理本次请求的 system prompt 和历史上下文：`回眸一号(ID:123)` 变成「回眸一号」，已知 QQ/群号换成称呼，带「QQ号/群号/电话」的数字换成「（已隐藏）」
- 只处理这次请求的副本；画像、关系网、共享记忆文件里的原始号码保留，不删数据
- 发给非主人会话的回复会做兜底：已知 QQ 号、群号，以及「QQ号/群号/电话/手机号/身份证」后面跟的数字，都会被替换成「（不方便说）」
- 主人私聊不处理，避免影响正常管理
- 关系网注入和共享记忆卡片不再携带 QQ 号；画像 H1 里的号码也不会进入注入摘要
- 只是兜底，人格提示词本身也要避免写出号码；发现模型主动报号时应优先改人格或记忆内容

## 用户关系网（v0.4.1）

在画像之外，单独维护一张**全局关系网**：所有群聊、所有私聊共用同一份数据，不会因为换群或换会话就重新认识一遍。

- **群聊和私聊都学**：记录对话原文（内存里滚动保留，默认 200 条），攒够素材后调用一次模型做保守抽取
- **宁不记不瞎记**：只接受「他是我哥」「这是我同事」「我们分手了」这类能被原话直接证明的关系；仅凭称呼、@、玩笑、语气、互动频率，一律不记
- **证据校验**：模型给出的 evidence 必须能在原始消息里找到，否则整条丢弃；双方必须是已知 QQ 号，且说这句话的人必须是关系双方之一
- **私聊怎么映射**：私聊里只有一个对话对象，所以必须**点名一个已知用户**（如「小明是我同事」且小明有画像/已在关系网里）才会记录；只叫「我同事」不会瞎猜
- **跨群共享**：在 A 群学到的关系，在 B 群、私聊里都能用；每条证据会记录来自哪个群/私聊
- **多种关系**：同一对用户可以同时是「同事 + 朋友」，分开记录；`detail` 可补充「母子」「上级」等具体说法
- **随时间变化**：出现分手、离婚、离职、绝交等明确表述时标记为已结束，保留历史；长期没有新证据的关系按半衰期（默认 180 天）慢慢变淡，但不会删除
- **注入**：在任意会话里，把当前出现的人（群聊）或对话对象（私聊）相关的有效关系压缩成一小段注入（默认最多 6 条），只用于理解称呼和语气，提示模型不要主动挑明

关系数据单独存放，**不会写进任何人的画像文件**：

- 默认路径：画像目录旁边的 `关系/relations.json`（例如 `C:\Evelyn_Snow\关系\relations.json`）
- 可用 `relations_dir` 指定其他目录
- 结构是全局 `edges` 列表；每条关系包含双方 QQ、昵称、类型、置信度、原话证据、来源会话、首次/最近时间、变更历史

### 向熟人打听（v0.5.0）

当模型在对话里察觉到两人**可能有关系**、但没有直接原话时，会先记成一条“猜测”（只保存在 `suspects` 里，不注入、不当事实），然后找一个足够熟的熟人私下问一句：

- 只问和双方同群、最近私聊过、熟悉度达到 `gossip_min_familiarity`（默认 68，约「好友」）的人
- 只在 `gossip_windows`（默认午休/下班后）检查，静默时段不发
- 默认每天最多 1 次、两次间隔 20 小时、同一个猜测最多问 1 次；30 天没有新线索就作废
- 问法由人设模型生成（失败用固定模板），只问“是不是”，不下结论，也不在群里公开八卦
- 如果对方真的给出明确回答，会作为新的对话证据进入正常的关系抽取

### 主人引荐（v0.6.3）

关系网只记「能被原话证明」的关系，但**新人还没有 QQ 名录**时，就算管理员明说「我找了几个朋友/同事来加你」，也无法把人和话对上。主人引荐补上这一环：

- **识别**：管理员（哥哥）说「我找了几个好友同事来加你」「这是我同事想认识你」这类话时，记一条引荐（含原话、时间、类型：同事/同学/室友/朋友）
- **兑现**：`intro_window_days`（默认 14 天）内，一个**从没聊过的新人**第一次冒头，就自动在关系网里建边「哥哥 —[同事]— 新人」（证据是哥哥的原话），并给这个用户打上引荐标记
- **生效**：之后和她聊天时，熟悉度按 `intro_floor`（默认 40，约「熟人」）保底注入，并附一段 `[引荐]` 说明——把TA当哥哥带来的熟人，放松自然可以接梗，但别主动打听私事、也别因为引荐就无条件答应；真实熟悉度涨过保底后自然接管
- **不误伤**：只有管理员的话算引荐；老用户不会被追溯关联；引荐只在窗口期内对新人生效

## 跨会话共享记忆（v0.6.0）

除了画像和关系网，再单独维护一个**共享记忆区**，让她能把别的对话里值得记的事带到当前聊天：

- **按会话汇总成卡片**：每个私聊/群聊的对话每攒够 `shared_min_exchanges` 轮、间隔够久，就调用一次模型生成 1~3 张卡片
- **来源可区分**：每张卡片带来源聊天（如「和哥哥的私聊」「群聊『xxx』」），注入时按来源标注
- **分享评级**：每张卡片由模型给出 `share_level`：
  - `0` 绝密：密码、健康、证件、财务等，任何聊天都不提
  - `1` 私密：只适合当事人/主人知道
  - `2` 熟人可提：当事人、同群成员，或与当事人有明确关系的人可以知道
  - `3` 公开：任何聊天都可以自然提起
- **关系网联动**：`share_level=2` 时，会用关系网判断当前听众和当事人有没有明确关系；没有关系就不提
- **注入**：每次聊天从**其他会话**里按相关度挑最多 4 张卡片，注入一小段 `[共享记忆]`，并提示不要主动说“另一个聊天”、不要复述隐私细节
- **边界**：和自动日记一样，只记录机器人实际回复过的对话；纯群友闲聊不会进卡片

数据文件默认在画像目录旁边的 `共享记忆/cards.json`，不写进任何人的画像文件。所有会话共享这一份卡片列表。

## 熟悉度（v0.3.0）

画像 frontmatter 新增 `印象评分`、`熟悉度`、`熟悉等级`、`活跃天数`、`首次互动`、`最近互动`：

- **印象分**：画像更新时模型给 0-100 的整体印象，代码按 `impression_smooth_alpha` 平滑，避免一次对话大起大落
- **熟悉度**：`45% 聊天频率 + 30% 印象分 + 25% 道德分`，再乘一个 0~1 的置信度（互动次数/活跃天数），避免刚聊几句就“熟人”
- **等级**：陌生 → 眼熟 → 认识 → 熟人 → 朋友 → 好朋友 → 好友 → 亲近 → 知己
- **上限**：非管理员最高 94（知己）；管理员/主人单独 100「管理员」，永远在最高档
- 聊天注入会带上熟悉度和对应分寸提示：陌生保持距离，朋友可接梗，知己更放松
- **主动私聊**：只在 `proactive_windows`（默认午休 12:00-13:30、下班后 18:00-22:00）检查；达到 `proactive_min_familiarity`、最近活跃、安静够久、过了冷却且概率命中，才会主动发一句
- **虚拟人生联动**：读取今日日程的当前活动；睡觉/上课/忙/在路上/低可打扰度时不发；生成消息会结合她正在做的事（如“刚下课在食堂排队”），不凭空编
- 管理员/主人默认排除（仍由 proactive_chat 负责），避免双份消息

## 道德评价（v0.2.0）

画像自带**道德评分（0-100，初始 75）+ 文字佐证**，放在 `## 道德评价` 小节：

- 每条记录格式 `- [±N] 用你自己的话写一句判断：『引用对方原话』（日期）`——**评分必须有原话支撑**，不允许只给数字
- 恶劣引导 / 教唆违规 / 骚扰暗示 / 人格侮辱：每次 −10~−25；**真诚道歉或改正 +5~+15**（部分恢复，总分不超过 85）；观点不同、玩笑、普通粗口不扣分
- 等级：≥70 正常；40–69 **警戒**；<40 **恶劣**

**等级的后果**（均可配置或关闭）：

| 等级 | 态度 | 回复延迟 | 群聊忽略 | 私聊忽略 |
|---|---|---|---|
| 警戒 | 冷淡、少耐心、提醒言辞 | ~12 秒 | 30% | 20% |
| 恶劣 | 明显不耐烦、简短敷衍、**可直接指责** | ~35 秒 | 60% | 40% |

- **群聊**：@ 机器人和命令不受影响（当面指责需要她能回话）
- **私聊**：也降频但概率更低（恶劣 40%、警戒 20%），表现为已读不回
- **所有者 / 管理员 / 网页测试台永不忽略**——再怎么扣分也要能跟他说话
- 佐证会注入给模型：她指责时引用的是对方自己说过的话
- 道歉恢复由模型在画像更新时依据对话判定，评分回升但受 85 封顶

## 依赖

- 纯标准库实现，无第三方依赖。
- 画像更新使用当前会话正在使用的聊天模型，每次更新约一次普通对话的 token 消耗。
