# Bot 用户画像

为每个聊天对象维护一份**持续更新的画像档案**：以 QQ 号为唯一索引（昵称随时会变，只作展示并记录改名史），每人一个 `<QQ号>.md`，聊天时自动把对方画像注入上下文，让机器人越聊越懂对方。

## 行为

- **采集**：每次「TA 说 / 我答」的交流按用户归档（含群成员，可配置），默认网页测试台不计入
- **更新**：同一用户攒够新素材（默认 6 条）且过了门槛（间隔默认 3 小时、每天最多 4 次、凌晨静默）才调用一次模型重写画像正文；frontmatter（昵称、曾用名、互动次数、更新时间）由插件管理，不消耗模型
- **注入**：对方来消息时，把画像精简版（默认 ≤400 字）注入本轮上下文，模型可自然参考但不会复述档案
- 画像章节：基本信息 / 性格与说话风格 / 兴趣话题 / 相处要点 / 最近动态；只写对话中有依据的内容，不编造

## 文件

默认存放在插件数据目录 `profiles/`；可在配置里填任意绝对路径（例如 Obsidian 仓库下的「画像」文件夹），方便直接翻看编辑。文件以 QQ 号命名，手改后下次更新会以你的版本为基础继续合并。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| enabled | true | 总开关 |
| profiles_dir | 空 | 画像目录；留空用插件数据目录 |
| include_groups | true | 群成员也建画像 |
| include_webchat | false | 网页测试台对话计入（无 QQ 号，以会话尾段命名） |
| min_new_messages | 6 | 触发更新的最少新对话条数 |
| min_interval_minutes | 180 | 同一用户两次更新的最小间隔 |
| max_per_day | 4 | 每用户每天更新上限 |
| max_buffer_per_user | 24 | 每人对话缓冲条数上限 |
| inject_limit_chars | 400 | 注入画像的最大字数 |
| quiet_hours | 0-6 | 不调用模型更新画像的静默时段（注入不受影响） |

## 依赖

- 纯标准库实现，无第三方依赖。
- 画像更新使用当前会话正在使用的聊天模型，每次更新约一次普通对话的 token 消耗。
