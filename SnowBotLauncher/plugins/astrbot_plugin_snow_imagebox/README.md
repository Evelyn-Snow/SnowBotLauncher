# 图库

让机器人把聊天里值得留下的图片/表情包存到本机，之后按情绪或场景再发出来。

## 目录

默认图库：

```text
~/Documents/BotMemory/表情包\
├─ images\        # 图片文件
├─ index.json     # 描述、标签、使用次数、时间
└─ cleanup.log    # 自动清理记录
```

可以在插件配置里改 `library_path`。

## 用法

- 发表情包并说“记住这个表情包”“存进图库”“以后用”，机器人会调用 `save_image_to_library`
- 说“发一张生气的表情包”“来个无语的图”，机器人会搜索并发送
- 说“看看图库”“图库有多少图”，会返回编号、描述、标签和统计
- 说“清理图库”，会立刻按规则清理

## 自动收藏

除了用户明确说“记住/收藏”，机器人也会自己判断：画面情绪或梗明确、以后可能复用时，才保存并打 2-5 个标签。

默认限制：

- 两次自动收藏至少间隔 45 分钟
- 每天最多 8 张
- 只在所有者的私聊里自动收藏；群聊默认不自动存
- 自动收藏概率 100%（模型判断值得存就存）；可以把 `auto_save_probability` 调低，让它更克制
- 隐私关键词（身份证、聊天记录、截图等）会被拦截

用户明确要求保存时不受这些频率限制。所有参数都在插件配置里，可以随时调整。

## 自动清理

每次启动后和每隔 `cleanup_interval_hours` 小时执行一次：

1. 超过 `retention_days` 天且使用次数低于 `min_uses` 的图删除
2. 超过 `max_items` 张时，按使用次数、最后使用时间淘汰最不常用的
3. 超过 `max_total_mb` 时，继续淘汰最不常用的

清理只动 `index.json` 里登记过的图片，不会删用户自己放进目录的其他文件。

## 与 QQ 原生表情包收藏的关系

NapCat/OneBot v11 没有提供“把图片加入 QQ 客户端表情包收藏”的接口，所以这里存的是机器人自己的本地图库；聊天时以图片消息发送，效果和发表情包一样，但不会出现在 QQ 客户端的表情面板里。
