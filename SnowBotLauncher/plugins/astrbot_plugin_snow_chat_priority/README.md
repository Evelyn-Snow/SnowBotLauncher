# 对话优先

解决「和她聊两句就被虚拟日程劝退」的问题，不改 virtual_life 源码。

## 做什么

1. **软化状态约束**：virtual_life 每轮会注入 `<character_state>`，末尾硬编码
   「普通回复必须与当前状态保持一致」。本插件在它之后（更低优先级）把这句话换成：
   「当前状态只作为语气和话题背景；对方来找你时以对话为先，不要主动说『先不聊了』，
   只有确实要睡觉、出门或上课迟到时，才自然地说晚点聊。」
2. **连续对话优先**：记录每个会话最近的消息时间；同一会话在窗口内达到消息数时，
   追加「你们正在连续聊天，先别主动结束；日程只当背景」。主人私聊阈值更低
   （默认 5 分钟 / 1 条），普通会话默认 10 分钟 / 2 条。

virtual_life 升级改了文案也不会丢：找不到原句时会追加一段「日程背景」说明兜底。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| enabled | true | 总开关 |
| soften_virtual_life | true | 改写「必须符合当前状态」为对话优先 |
| active_window_minutes / min_turns | 10 / 2 | 普通会话连续判定 |
| owner_window_minutes / owner_min_turns | 5 / 1 | 主人私聊连续判定 |

## 说明

- 只改 LLM 请求里的提示词，不改消息、不改数据库
- 连续判定只存在内存里，重启后重新累计
- 群聊仍然保留边界感：没聊起来时，她依然可以按日程做事
